# Conversión de Coordenadas

Página web para enseñar y prácticar  **la conversión de coordenadas**, un tema de física.

🔗 **Demo:** [Ver en línea](https://eloadev.github.io/proyects/Coordenadas/graficar/)

![Coordenadas](img/calculadoras.png)

## Descripción

Este proyecto ayuda a graficar y practicar ejercicios de física relacionados con conversión de coordenadas. La página explica brevemente en qué consiste el tema e incluye guías paso a paso.

## Cómo funciona

1. El usuario lee una breve explicación del proyecto.
2. Elige lo que necesita que necesita:
   - **Graficar:**guias para gráficar en papel o en geogebra.
   - **Formulas:** guias de formulas para hacer conversiones entre coordenadas. 
   - **Practicar:** guias de ejercicios para que el usuario resuelva. 
3. Lee los apoyos visuales (tarjetas).
